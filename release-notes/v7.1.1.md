# Changelog

### Other Changes ☀️
- `f4ba515` The README and the getting-started guide show the simple path first: a runnable `FixtureViClient` example with the `Vitocal250A` fixture, then the same code with `ViClient`. The getting-started guide walks through reading values, changing a setting, refreshing, and switching to the real client ([#219](https://github.com/ignazhabibi/vi_api_client/pull/219)).
- `4171aa7` Every reference page now leads with the everyday case: the API structure guide shows the raw heating-curve JSON next to one `set_feature` call, the client reference opens with the methods you need, the models reference with the four core models, and the exceptions reference with a ready-to-use handler ([#220](https://github.com/ignazhabibi/vi_api_client/pull/220)).
- `e0f4bec` The internal command knowledge that tells the library how to write a feature is now called a write command, and its fields on `Feature` and `Device` are private. This was never public API; consumers keep using `feature.is_writable`, `feature.constraints`, and `device.get_command_names(...)` ([#218](https://github.com/ignazhabibi/vi_api_client/pull/218)).
- `41b4218` The `dev` extra pins Ruff 0.17.5 ([#213](https://github.com/ignazhabibi/vi_api_client/pull/213)).
