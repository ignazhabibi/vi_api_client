# Changelog

### Breaking Changes 🚨
- `91e064a` Remove `mask_identifiers` and `vi_api_client.utils.mask_pii`; use `redact_sensitive`, which now also redacts log text. Log redaction uses `#` and masks identifiers without a known prefix ([#172](https://github.com/ignazhabibi/vi_api_client/pull/172)).

### New Features 💫
- `91e064a` Redact secrets, address data, identifiers, and coordinates with one rule set: `redact_sensitive` for log text and JSON, `redact_feature` and `redact_device` for model objects ([#172](https://github.com/ignazhabibi/vi_api_client/pull/172)).
