# Changelog

### New Features 💫
- `060971d` Add a synthetic `currentDay` alias for `heating.power.consumption.{cooling,dhw,heating,total}`, mirroring `day[0]` with the unit of the `day` series, alongside the existing `currentYear` alias. `total.currentDay` passes the API value `total.day[0]` through unchanged and can lag behind `heating` + `dhw` for the running day ([#184](https://github.com/ignazhabibi/vi_api_client/pull/184)).
